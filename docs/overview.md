# プロジェクト概要

## 目的

RAGシステムにおいてチャンク戦略の選択は検索精度・回答品質に大きく影響するが、
その影響を定量的に把握する手段がなく、経験則に頼りがちになる。

ragprepは「チャンク戦略が検索精度と回答品質に与える影響」を閉じたループで
実験・記録するフレームワークである。

## スコープ

### やること

- チャンク戦略の定義・実行・チャンク結果の保存
- OpenAI APIを使った埋め込みの生成
- ローカルベクトル検索による検索精度の測定（Recall@k、MRR）
- LLM回答生成とLLM as a judgeによる回答品質評価
- 複数戦略の実験結果の記録・比較

### やらないこと

- 本番ベクトルDBへのインデックス登録
- リアルタイム検索・クエリ実行
- 本番環境向けのデプロイ機能
- RAGパイプライン後段の最適化（リランカー、マルチクエリ等）

## 成功の定義

- 同じ設定で実験を再現できる
- 複数のチャンク戦略の検索精度・回答品質をメトリクスで比較できる
- 新しいチャンク戦略を設定ファイルだけで追加できる
- コードベースの品質が高く、長期メンテナンスに耐えられる
