# プロジェクト概要と目的

## このツールが解決する問題

RAG実装において、チャンク戦略やプロンプト戦略の試行錯誤は経験則に頼りがちで、「なぜこの設定が良かったか」の根拠を残しにくい。再現性のある実験管理の仕組みが存在しない。

## スコープ

### やること

- チャンク戦略の定義・実行・結果保存
- プロンプトテンプレートのバージョン管理
- 実験の実行・記録（再現性担保）
- 実験結果の比較・メトリクス表示

### やらないこと

- ベクトルDBへの実際のインデックス登録
- LLMを使った回答精度の評価（RAGパイプラインの後段）
- リアルタイムの検索・クエリ実行
- 本番環境向けのデプロイ機能

## 成功の定義

- 同じ設定で実験を再現できる
- 複数のチャンク戦略の結果をメトリクスで比較できる
- 新しいチャンク戦略を設定ファイルだけで追加できる
